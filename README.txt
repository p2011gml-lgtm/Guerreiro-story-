GUERREIRO STORY — SITE PARA GITHUB PAGES

1. Extraia este ZIP.
2. Envie index.html, style.css, script.js e a pasta images para a raiz do repositório GitHub.
3. Em Settings > Pages, selecione Deploy from a branch, branch main e pasta /(root).

IMPORTANTE ANTES DE PUBLICAR:
- No script.js, procure const whatsapp='' e coloque o número oficial da loja com código do país e DDD, só números. Exemplo de formato: 55DDDNUMERO.
- O catálogo usa fotos extraídas do primeiro catálogo PDF fornecido. Confira a correspondência de cada foto e preço com a loja antes de publicar.
- Os dados de tamanhos/cores podem variar por estoque; confirmar com a loja.
- O pedido não é pagamento online: abre o WhatsApp para a loja confirmar disponibilidade.
- Looks prontos aplicam desconto de 5%. O montador personalizado soma os preços das peças sem desconto.
